# Security

[![한국어](https://img.shields.io/badge/lang-한국어-blue)](SECURITY.ko.md)

Please report security problems privately, not in a public issue.

This covers the viewer at https://hd2-replay.code0987.me and its share and library service. For example:

- access to someone else's saved replays
- bypassing upload limits
- running script through a shared replay

## How to report

Use **Report a vulnerability** on the [Security tab of the translations repository](https://github.com/hd2-history-viewer/translations/security/advisories/new). Only the maintainers see the report.

Please include what you did, what you saw, and a replay share link if one is involved. Do not access, change or delete other people's data beyond what you need to show the problem.

This is a spare-time project, so there is no bounty. Every report is read, and credited if you wish.
