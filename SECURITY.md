# Security · 보안

Please report security problems privately, not in a public issue. This covers the viewer at https://hd2-replay.code0987.me and its share and library service, for example access to someone else's saved replays, bypassing upload limits, or a way to run script through a shared replay.

보안 문제는 공개 이슈가 아니라 비공개로 알려 주세요. 대상은 https://hd2-replay.code0987.me 뷰어와 공유·보관함 서비스입니다. 예: 다른 사람의 저장 리플레이에 접근하기, 업로드 한도 우회, 공유 리플레이로 스크립트 실행.

## How to report · 제보 방법

Use **Report a vulnerability** on the [Security tab of the translations repository](https://github.com/hd2-history-viewer/translations/security/advisories/new). Only the maintainers see the report.

[translations 저장소의 Security 탭](https://github.com/hd2-history-viewer/translations/security/advisories/new)에서 **Report a vulnerability**를 눌러 주세요. 제보 내용은 관리자만 봅니다.

Please include what you did, what you saw, and a replay share link if one is involved. Do not access, change or delete other people's data beyond what is needed to show the problem.

무엇을 했고 무엇이 보였는지, 관련된 공유 링크가 있으면 함께 적어 주세요. 문제를 보이는 데 필요한 범위를 넘어 다른 사람의 데이터에 접근하거나 바꾸거나 지우지 마세요.

This is a spare-time project, so there is no bounty, but every report is read and credited if you wish.

여가 시간에 운영하는 프로젝트라 포상금은 없지만, 모든 제보를 확인하고 원하시면 이름을 밝혀 감사를 표합니다.
