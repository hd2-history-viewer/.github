## HD2 History Viewer

[![한국어](https://img.shields.io/badge/lang-한국어-blue)](https://github.com/hd2-history-viewer/.github/blob/main/profile/README.ko.md)

An unofficial web replay viewer for [HD2 History](https://www.nexusmods.com/helldivers2/mods/17182) mission exports from Helldivers 2. It shows the mission map, squad paths, events and results, in Korean and English. Logs are read in your browser.

- **Viewer:** https://hd2-replay.code0987.me
- **Report a bug, a wrong name or an idea:** [open an issue](https://github.com/hd2-history-viewer/translations/issues/new/choose)
- **Translations:** [translations](https://github.com/hd2-history-viewer/translations), the Korean/English language pack. Pull requests welcome.

Please do not attach raw mission logs to issues. They contain other players' names; paste the viewer's share link instead.

Not affiliated with Arrowhead Game Studios or the HD2 History mod authors.
