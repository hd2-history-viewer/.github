## HD2 History Viewer

An unofficial web replay viewer for [HD2 History](https://www.nexusmods.com/helldivers2/mods/17182) mission exports from Helldivers 2: mission map, squad paths, events and results, in Korean and English. Logs are read in your browser.

Helldivers 2 [HD2 History](https://www.nexusmods.com/helldivers2/mods/17182) 모드의 임무 기록을 재생하는 비공식 웹 뷰어입니다. 임무 지도, 대원 경로, 사건과 결과를 한국어와 영어로 볼 수 있고, 로그는 브라우저 안에서만 읽습니다.

- **Viewer · 뷰어**: https://hd2-replay.code0987.me
- **Report a bug, a wrong name or an idea · 버그·이름 오류 제보와 제안**: [open an issue · 이슈 열기](https://github.com/hd2-history-viewer/translations/issues/new/choose)
- **Translations · 번역**: [translations](https://github.com/hd2-history-viewer/translations) — Korean/English language pack; pull requests welcome. · 한국어·영어 언어 팩, 풀 리퀘스트 환영

Please do not attach raw mission logs to issues: they contain other players' names. Paste the viewer's share link instead.
이슈에 임무 로그 원본은 올리지 마세요. 다른 플레이어 이름이 들어 있습니다. 대신 뷰어의 공유 링크를 붙여 주세요.
