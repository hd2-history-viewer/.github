## HD2 History Viewer

[![English](https://img.shields.io/badge/lang-English-red)](https://github.com/hd2-history-viewer)

Helldivers 2 [HD2 History](https://www.nexusmods.com/helldivers2/mods/17182) 모드의 임무 기록을 재생하는 비공식 웹 뷰어입니다. 임무 지도, 대원 경로, 사건과 결과를 한국어와 영어로 보여 줍니다. 로그는 브라우저 안에서만 읽습니다.

- **뷰어:** https://hd2-replay.code0987.me
- **버그·이름 오류 제보와 제안:** [이슈 열기](https://github.com/hd2-history-viewer/translations/issues/new/choose)
- **번역:** 한국어·영어 언어 팩 [translations](https://github.com/hd2-history-viewer/translations). 풀 리퀘스트를 환영합니다.

이슈에 임무 로그 원본은 올리지 마세요. 다른 플레이어 이름이 들어 있습니다. 대신 뷰어의 공유 링크를 붙여 주세요.

Arrowhead Game Studios나 HD2 History 모드 제작자와 관련이 없는 비공식 프로젝트입니다.
